无法登录？使用 auth_token 授权
  1. 打开 code for me 并登录。
  2. Chrome / Edge 按 F12（Mac 可按 ⌥⌘I）打开开发者工具，切换到 Application（应用）；找不到时展开顶部 » 菜单。
  3. 左侧展开 Local Storage（本地存储），选择地址栏对应的当前站点，如 https://blackaicoding.com。
  4. 找到键名 auth_token，双击右侧 Value（值） 单元格，复制完整内容，粘贴到下面并验证。只复制值，不包含键名、引号或 Bearer 前缀。
  1. 打开 Aixor 钱包 并登录。
  2. Chrome / Edge 按 F12（Mac：⌥⌘I）打开开发者工具 → Network（网络），刷新页面。
  3. 搜索 /api/user/self，点开该请求 → Headers（标头） → Request Headers（请求标头）。
  4. 复制 Cookie 的完整值到下方（不含 Cookie: 前缀），再复制 New-Api-User 的数字值。若看不到用户 ID，可在 Application → Local Storage → https://aixor.cc 中复制 uid。
  5. 点击「验证并保存会话」。会话失效后重新登录即可。
