    自动切换设置

    中转商优先

    只有加入池子的入口参与选择。同一中转商共用优先级，数字越小越优先；绿色候选始终先于黄色候选。

    M/N 为全局设置，低于才跳过，等于仍可使用。订阅满足 M 时优先使用该商的订阅入口，否则检查余额入口。切入候选须能确认所用额度；当前入口仅因查询失败或网页登录过期时继续使用，确认额度不足或套餐失效后才切换。

    已确认额度不足或套餐失效后，后续查询失败不会解除排除；开关自动切换、重新登录或重启服务也会保留记录，直到新的成功查询确认恢复。调低 M/N 后，旧金额不再低于新阈值时改为待确认，查询失败的入口仍不能作为新候选。

    请选择已在中转商处配置好扣费方式的 Key / 地址，并将订阅入口关联到它实际使用的套餐。本工具通过换入口切换扣费来源，不修改中转商后台设置。次数和积分额度无法换算美元时会跳过。

    检测模型应与实际调用模型一致，此处不会修改请求模型。有效检测明确不可用或实际调用失败时，有合格候选就立即切换；查询失败、样本过期、缺少数据或网页登录失效只提示并继续检测，不因此切换当前入口。网页登录失效不等于调用 API Key 失效。最近 3 分钟的恢复判断仅用于候选重新入选，不延迟故障切出；单格超过 3 分钟时取最近一格。服务运行期间后台每 15 秒检查，关闭页面仍生效。手动换站会关闭自动切换。

    code for me · 监控授权

    使用 code for me 账号登录，自动读取监控和账号余额。

    密码仅用于本次登录，不会保存。授权自动保存在本机，到期后在这里重新登录即可。

    无法登录？使用 auth_token 授权
    1. 打开 code for me 并登录。
    2. Chrome / Edge 按 F12（Mac 可按 ⌥⌘I）打开开发者工具，切换到 Application（应用）；找不到时展开顶部 » 菜单。
    3. 左侧展开 Local Storage（本地存储），选择地址栏对应的当前站点，如 https://blackaicoding.com。
    4. 找到键名 auth_token，双击右侧 Value（值） 单元格，复制完整内容，粘贴到下面并验证。只复制值，不包含键名、引号或 Bearer 前缀。
    1. 打开 Aixor 钱包 并登录。
    2. Chrome / Edge 按 F12（Mac：⌥⌘I）打开开发者工具 → Network（网络），刷新页面。
    3. 搜索 /api/user/self，点开该请求 → Headers（标头） → Request Headers（请求标头）。
    4. 复制 Cookie 的完整值到下方（不含 Cookie: 前缀），再复制 New-Api-User 的数字值。若看不到用户 ID，可在 Application → Local Storage → https://aixor.cc 中复制 uid。
    5. 点击「验证并保存会话」。会话失效后重新登录即可。
